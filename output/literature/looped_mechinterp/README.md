# License-Audited Bibliography & Fetched PDFs of Cited Looped-Transformer Papers

This directory archives **Creative Commons (`CC BY 4.0`)** PDF snapshots in the public `MoralityLabAI/VPD` repository and records verified SHA-256 checksums, byte counts, license URIs, and canonical arXiv PDF links in [`manifest.json`](manifest.json) for all 15 cited external looped-transformer and equilibrium-model papers.

> **License policy:** Papers published under `CC BY 4.0` (`http://creativecommons.org/licenses/by/4.0/`) permit redistribution with attribution and are hosted directly here so every public `Repo PDF` link resolves anonymously (`HTTP 200`). Papers under arXiv's default `non-exclusive license 1.0` (`http://arxiv.org/licenses/nonexclusive-distrib/1.0/`) grant distribution rights only to `arXiv.org`; their binary PDFs are excluded from public mirroring and referenced via canonical `arxiv.org/pdf` links plus verified SHA-256 hashes in [`manifest.json`](manifest.json).
